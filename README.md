# Kalman_Filter_Multivariate
A multivariate Kalman filter for processing noise in linear systems.

'Kalman_Filter_Class.py' contains only the class required for implementation.

'Multivariate_Kalman_Filter_Demo.ipynb' contains a demonstration of the filter.

'A Multivariate Kalman Filter for Tracking a Bouncing Ball: Derivation and Implementation' contains an example implementaition and results for the filter.
